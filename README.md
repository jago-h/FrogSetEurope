## FrogSetEurope
This repository hosts the custom code used to compile, curate, and validate the FrogSetEurope metadata manifest, together with collecting the corresponding recordings from Xeno-canto, Observation.org and iNaturalist. 
FrogSetEurope is a curated, fully harmonized bioacoustic audio and metadata index of 8.684 anuran vocalization recordings spanning 37 species across the European continent. It provides a community resource for research on European anuran bioacoustics and automated acoustic analysis.

The dataset including the audio files can be found at the accompanying Zenodo release: https://zenodo.org/records/21282595.
